# Integration Bee · אוניברסיטת תל אביב

אתר תחרות האינטגרלים של הפקולטה למדעים מדויקים. אתר סטטי (HTML/CSS/JS), ללא שלב בנייה, מוכן ל־GitHub Pages.

## עמודים
- `index.html` — דף הבית: הרשמה לתחרות הקרובה, מבנה התחרות, אלופי 2026, הצוות האקדמי
- `archive-2026.html` — מבחן המוקדמות, אינטגרלי הגמר עם תשובות, מצגת הגמר, חידון ניוטון/לייבניץ, תמונות וקבצים
- `simulation.html` — סימולציה: מבחן מוקדמות מלא (30 דקות) או אינטגרל אקראי מהגמר

## עדכון פרטי ההרשמה
כל הפרטים של התחרות הקרובה נמצאים בראש `assets/js/data.js` (`SITE_CONFIG`):
קישור לטופס ההרשמה, מועדי המוקדמות, מועד ומקום הגמר וכתובת ליצירת קשר.
שדה ריק מוצג באתר כ״יפורסם בהמשך״ / ״ההרשמה תיפתח בקרוב״.

## הוספת שנה חדשה
האינטגרלים נשמרים ב־`assets/js/data.js` בכתיב LaTeX. לשנה חדשה מעתיקים את `BEE_2026`, את `archive-2026.html`, ומוסיפים קישור בתפריט.

## פרסום ב־GitHub Pages
Settings → Pages → Source: *Deploy from a branch* → Branch: `main`, תיקייה `/ (root)`.
האתר יעלה בכתובת `https://kerenmorwak.github.io/tau-integration-bee/`.

גופנים (Assistant, Secular One, Bebas Neue) ו־KaTeX מאוחסנים בתוך הריפו, כך שהאתר לא תלוי בשירותים חיצוניים.
